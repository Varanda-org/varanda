### Adicionado

- `node scripts/bunny.js` configura pela API do Bunny a zona na frente de `/media/*` (PR `feat/bunny-setup-script`): `plan` mostra o que mudaria sem escrever nada, `apply` cria a zona, grava os ajustes (cache velho desligado, registros com anonimização "Drop"), o hostname e as três Edge Rules (o segredo `X-Varanda-Edge`, bloqueio fora de `/media/`, cache de 60 s), confere tudo lendo a zona de novo e, rodado outra vez, não escreve nada; `cert` pede o certificado só depois que o CNAME aponta para o Bunny, `purge` limpa caminhos de `/media/` e `status` só lê. Quem roda é o mantenedor, no próprio terminal: a chave vem de `BUNNY_API_KEY` ou de uma pergunta sem eco, o segredo vem do `.env`, e nenhum dos dois aparece na saída. Passos em `docs/cdn.md`, seção "Bunny"; verificação em `docs/verification/feat-bunny-setup-script.md`.
