### Adicionado
- Páginas nos grupos privados pelo nó core, só texto: com `--account-origin`, um administrador delegado que guarda as chaves da Página lê os grupos privados como a Página (`group.read` com `page`) e lacra publicações para o escritor dela (`group.seal`), com os mesmos estados e erros do navegador ("sem chave da página", "aguardando nova chave"). Foto, voz e cartão de link em nome da Página continuam só na versão web e são recusados antes de usar qualquer chave. A sincronização do nó core passa a buscar os grupos em que as Páginas guardadas estão. Sem `--account-origin`, nada muda.
